# みやきカントリークラブ 公式サイト 引き継ぎ書

最終更新：2026年7月

---

## 1. このサイトについて

- **1枚のHTMLファイル（`index.html`）だけで完結**する静的サイトです。
- 画像はすべてHTMLファイル内に**base64で埋め込み**（外部サーバー・外部URLに依存しない）。
- **GitHub → Vercel** で公開。公開URL：`miyakicc.vercel.app`

---

## 2. 更新のやり方（いちばん簡単な方法）

写真の追加・差し替えは、**チャット（Claude/クロウド）に頼むだけ**でOKです。

1. チャットに**写真をアップロード**し、「**この写真をここに入れて**」と一言添える
   （例：「3番ホールのティーショット」「ギャラリー1枚目」「ヒーロー差し替え」など）
2. Claudeが画像を最適化して埋め込み、**2ファイル**で返す：
   - **`index.html`** … 本番用（GitHubに上げるファイル）
   - **`index-preview.html`** … 確認用（チャット内で画像込みでプレビューできる。中身は本番と同じ）
3. GitHub上の `index.html` を差し替えて **push** → **Vercelが自動で再デプロイ**

> ※ 確認用に `index-preview.html` を分けている理由：チャットのプレビュー画面は外部画像を表示できないため、画像を埋め込んだ確認用ファイルが必要になるため。

---

## 3. デプロイ（公開）の仕組み

- リポジトリ直下に `index.html` を置く（ファイル名は必ず `index.html`）。
- Vercelでリポジトリをimportするだけ（ビルド設定は不要・静的サイト）。
- 以降は **push するたびに自動で本番反映**。

---

## 4. 自分でHTMLを編集する場合の写真の入れ場所

Claudeに任せる場合は不要ですが、参考まで。すべて `index.html` の末尾付近のコードにあります。

- **ヒーロー（TOP）背景**：`<img class="hero-photo" src="...">` の `src`
- **コース案内の写真**：`<div class="course-vis"><img src="...">`
- **コースガイド 各ホール**：JavaScriptの `holes` 配列
  - `tee` / `second` / `green` に画像、`comment` に攻略コメント
- **Instagram**：JavaScriptの `igPosts` 配列
  - `img`（画像）/ `link`（投稿URL）/ `chip`（ラベル）/ `cap`（キャプション）

画像は「画像URL」でも「base64データURI」でも表示できます。
